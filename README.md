### 👨‍💻 Professional Summary

Results-driven **DevOps / DevSecOps Engineer & Cloud Consultant** with **6+ years of proven experience** designing, implementing, and managing highly available, secure, and scalable cloud infrastructure and CI/CD pipelines.

- ☁️ **Cloud Architecture & Governance:** Extensive hands-on expertise in **Microsoft Azure** (Virtual Networks, Management Groups, Storage Accounts, Load Balancers, Entra ID) implementing Cloud Adoption Framework (CAF) Landing Zones.
- 🏗️ **Infrastructure as Code (IaC):** Modular, reusable **Terraform** architecture with strict remote state management, module versioning, and **Bicep** templates.
- 🔒 **Shift-Left DevSecOps & Security Hardening:** Hardening workloads according to **CIS Benchmarks**, enforcing least-privilege via **Azure RBAC & IAM**, secret management through **Azure Key Vault**, NSG rules, and threat detection via **Microsoft Defender for Cloud**.
- 🚀 **Automated Delivery (CI/CD):** Building robust, repeatable build-test-deploy pipelines using **Azure DevOps (Azure Pipelines)** and **GitHub Actions** across dev, staging, and production tiers.
- ☸️ **Containerization & Orchestration:** Supporting and deploying production container workloads using **Docker** and **Kubernetes (AKS)**.
- 📈 **SRE, Observability & DR:** Comprehensive monitoring, alerting, and telemetry with **Azure Monitor, Log Analytics, Application Insights, Prometheus, Grafana, and ELK Stack**. Designing high-availability disaster recovery architectures with **Azure Backup** and **Azure Site Recovery (ASR)** (defining RTO/RPO targets).
- 💰 **Cloud Cost Optimization:** Driving cloud cost reductions through resource right-sizing, auto-shutdown schedules, and tagging governance.
